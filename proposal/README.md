# Sorgenti del portfolio

Questa cartella contiene il sito pubblico. Modificare qui HTML, CSS, JavaScript, SVG e dati; `npm run build` rigenera `dist/`.

Comandi e struttura sono descritti nel [README principale](../README.md). Le decisioni correnti sono in [PROJECT_CONTEXT](../docs/PROJECT_CONTEXT.md), mentre [STATUS](../docs/STATUS.md) registra verifiche e prossimi passi.

Il CV HTML è una sintesi pubblica. PDF originale, dati privati, credenziali e materiale di lavoro non appartengono a questa cartella.
